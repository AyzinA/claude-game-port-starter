# Example data mod (synthetic)

`demo-data-mod.zip` is a tiny **original, noncopyrighted data-only mod** for testing the browser preview. Select game profile ID `demo` and sideload this ZIP. It adds virtual resource `demo/example-data.json`. Nothing is executed and no specific commercial game is supported by this example.

For actual games, Claude Code must map the game’s native mod format/path conventions to the internal VFS after a feasibility and security audit.

For Docker/local auto-loading, copy an authorized installation to `public/game` and place mod ZIPs or folder mods in `public/mods`. See `docs/15-DOCKER-LOCAL-LIBRARY.md`.
